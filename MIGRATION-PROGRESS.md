## Instructions for Each Batch:

1. **Upload to Cloudinary:**
   - Go to Media Library
   - Create folder: `chuchi/images`, `chuchi/videos`, `chuchi/music`
   - Upload files to appropriate folders

2. **Get URLs:**
   - Copy Cloudinary URLs for each file
   - Format: `https://res.cloudinary.com/your-cloud-name/image/upload/v1/chuchi/images/filename`

3. **Update media-config.ts:**
   - Add mapping: `'/images/filename.jpg': 'cloudinary-url'`

4. **Test:**
   - Import `getMediaUrl` in component
   - Replace `src="/images/file.jpg"` with `src={getMediaUrl("/images/file.jpg")}`
   - Verify files load from Cloudinary

5. **Mark Complete:**
   - Check off files in this list
   - Only proceed to next batch when current batch works 100%
