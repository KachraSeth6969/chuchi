# 📱 Chuchi Love App - Installation Instructions

## 💝 About the App
This is your personal love app that contains all our memories, photos, and music. It has the same password protection as the website with session-based security.

## 📲 Installation Steps

### Step 1: Enable Unknown Sources
1. Open **Settings** on your phone
2. Go to **Security** or **Privacy & Security**
3. Enable **"Install unknown apps"** or **"Unknown sources"**
4. If prompted, allow installation from your file manager or browser

### Step 2: Install the App
1. Download the **Chuchi-LoveApp.apk** file to your phone
2. Open your **File Manager** or **Downloads** folder
3. Tap on **Chuchi-LoveApp.apk**
4. Tap **Install** when prompted
5. Wait for installation to complete
6. Tap **Open** or find "Chuchi" in your app drawer

### Step 3: Using the App
- **Password**: `supernova` (same as website)
- **Security**: App locks when you switch away or minimize it
- **Content**: Same as https://chuchii.vercel.app but optimized for mobile

## 🔐 Security Features
- ✅ Password required on every launch
- ✅ Auto-logout when app goes to background
- ✅ Session-only authentication (no saved passwords)
- ✅ Same security as our website

## 📋 App Details
- **File**: Chuchi-LoveApp.apk (5.5 MB)
- **Version**: 1.0
- **Platform**: Android 7.0+
- **Permissions**: Internet access only

## 🆘 Troubleshooting

**If installation fails:**
1. Make sure "Unknown sources" is enabled
2. Try downloading the APK file again
3. Restart your phone and try again

**If app shows white screen:**
1. Check your internet connection
2. Close and reopen the app
3. Make sure you can access https://chuchii.vercel.app in your browser

**If password doesn't work:**
1. Make sure you're typing `supernova` (all lowercase)
2. Check that your keyboard isn't adding extra spaces
3. Try closing and reopening the app

## 💌 Notes
- This app loads our website inside a secure container
- All your memories, photos, and music are the same as the web version
- The app works best with a stable internet connection
- You can delete and reinstall anytime without losing data
